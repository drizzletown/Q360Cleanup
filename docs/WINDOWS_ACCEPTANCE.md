# Windows / 360 实机验收协议

验收必须由受授权的测试者在可回滚虚拟机完成；每个案例保留快照、Windows 版本、360 精确产品版本、工具哈希、操作步骤、卸载退出状态、重启前后扫描报告、失败截图及恢复结果。日志必须脱敏。

| 场景 | 操作 | 合格判据 |
| --- | --- | --- |
| 基础 GUI / UAC | 标准用户、管理员用户分别启动 | 未提升权限不得悄然执行提权写操作，按钮及窗口正常 |
| 无 360 | 干净 Windows 10/11 | 不把系统组件认作目标，不提供误删路径 |
| 误报保护 | 安装 Autodesk Fusion 360/其他含 360 名称产品 | 不匹配或只读提示，不启动无关卸载器 |
| 企业产品 | 360 托管产品测试环境（须有组织授权） | 自动卸载范围明确排除，并且任何隔离动作停止 |
| 单产品 | 360安全卫士、360杀毒、360浏览器、360压缩各至少 1 当前版本 | 正规卸载向导可用，状态不误报，重启后复查 |
| 多产品 | 360 组合安装与共享组件 | 卸载一个产品不误删其他产品数据或共享服务 |
| 卸载失败 | 用户取消、卸载器缺失、MSI 1603/1618 等 | 明确失败诊断、停止自动串行卸载、保留完整会话 |
| 自保护启用 | 正常启用防护的 360 安全软件 | 工具不强杀进程、驱动或关闭自保护；无法完成时提示人工处置 |
| 残留证据 | 存在任务、服务、进程、启动项、目录 | 验收不得报告“范围内通过” |
| NTFS 安全 | Junction、symlink、跨盘、只读目录、权限拒绝 | 不越界、不覆盖，失败保留隔离记录和原文件 |
| 中断恢复 | 隔离前后模拟中断 | 能复核状态；不覆盖原目录；数据可恢复 |
| 重启判定 | 常规重启、睡眠与快速启动 | 同一次启动不能误报重启完成 |

执行 `./scripts/test-windows.ps1` 是进入实机验收前的代码测试，不会替代上述手工测试。

**判定**：出现任何误卸载、数据丢失、损坏恢复记录后继续修改、越权清理或不实成功结论，直接阻断 Stable 发布。实际数据应汇总到 `docs/REAL_WORLD_VALIDATION.md`，在完成测试之前保持“未验证”。
