# Q360 Cleanup v1.0.0 — GitHub 发布说明

**平台**：Windows 10/11 x64（便携式 EXE）｜**许可**：MIT｜**发布日期**：2026-11-19

这是从 v0.4.0 收敛的 v1.0.0 发布构建，面向**用户授权管理的个人设备**。产品实现了识别、可信卸载入口校验、官方卸载调度、卸载失败记录、只读残留诊断、有限用户目录的隔离与恢复、重启后范围内验收。它**不是**绕过 360 自保护或删除内核驱动的强制移除器。

## v1.0 的主要变化

- Windows 任务文件夹由 Windows 系统目录 API 确定，不信任 `WINDIR` 环境变量。
- Windows 进程枚举异常不再作为正常完成处理。
- 隔离清单对尾随数据严格拒绝，隔离记录 ID 使用随机生成，增强唯一性。
- 增加 Windows 原生路径欺骗、清单损坏等回归测试。
- 统一 v1.0.0 版本号，新增发布构建校验、Windows 自测脚本与人工确认的草稿 Release 流程。

## 已知限制（请在公开发布时保留）

1. 当前可执行文件没有代码签名，不等于认证发行者；Windows 可能显示未知发布者。
2. **没有**在此构建环境中运行 Windows GUI/UAC/360 软件实机全链路验收。需在可回滚测试虚拟机验证后才适合声明“正式稳定版”。
3. 检测结果来自有限系统范围，`范围内通过` 不能等同全机无残留。
4. 不关闭自保护、不禁用驱动、不强制清理服务/注册表；遇到损坏卸载器可能要求用户使用厂商官方支持流程。
5. 当前仅支持 Windows x64；日志保存在本机，包含路径信息，提交问题前必须脱敏。

**建议 GitHub Release 状态：Draft / Pre-release**，完成真实 Windows/360 测试并人工签署验收后再转换为正式 Stable。
