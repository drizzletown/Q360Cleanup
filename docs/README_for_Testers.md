# 测试者指引

这是 v1.0.0 的**公开测试候选**。请只在**自己所有或经授权管理**、具有系统快照或完整备份的 Windows 10/11 x64 测试机上运行。不能通过关闭 Defender/360 的防护或强杀驱动去实现所谓的“通过测试”。

建议按以下顺序测试：干净系统误报 → 单产品注册项识别 → 正规卸载器可启动 → 卸载失败与重启状态 → 多产品共存 → 残留只读审计 → 精确目录隔离及恢复 → 检查是否影响其他软件。

请为每一个结果记录 OS 版本、360 精确产品版本、工具 EXE 的 SHA-256、操作前后截图、操作日志、是否重启与有无用户数据损伤；不要上传用户名、用户目录或其他私人数据。详细标准见 [`WINDOWS_ACCEPTANCE.md`](WINDOWS_ACCEPTANCE.md)。

**任何误删或系统稳定性问题都应停止继续测试并恢复快照。**
