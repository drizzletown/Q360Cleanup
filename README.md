# Q360 Cleanup v1.0.0 — 360 全家桶卸不掉，试试这个。
**支持系统：Windows 10/11 x64。** 当前发布资产未经数字签名；真实安装 360 的环境尚未完成端到端验证，请优先在带有快照的测试虚拟机使用。

## 启动

1. 完整解压 ZIP，保持 `Q360Cleanup_Windows_x64.exe` 和 `启动-管理员模式.cmd` 位于同一个目录。
2. 备份书签、网盘数据及其他重要用户文件。
3. 右键启动脚本，或右键 EXE 选择以管理员身份运行，并确认 UAC。不要为了运行它而关闭安全防护。
4. 点击“扫描已安装产品”；核对名称、发布者及卸载入口。
5. 选择一项或多项产品，点击“卸载选中产品”，按照官方卸载器的交互步骤操作；进程未明确完成时不会继续盲目卸载下一项。
6. 重启，执行“深度诊断”和“重启后验收”。

## 结果说明

- **未开始**：尚未记录本工具发起的卸载会话。
- **卸载失败 / 流程未完成**：存在失败、中断、等待操作或尚未完成的目标。
- **等待重启**：产品安装登记可能已消失，但未观察到新的 Windows 启动会话。
- **需人工处置 / 残留待确认**：仍有后台服务、任务、启动项、目录或注册表线索。它们不能一概删除。
- **范围内通过**：本工具支持的检查范围内没有发现证据，并不保证整个系统无残留。
- **无法判定**：任一必要扫描失败或会话损坏，不能报告成功。

## 可恢复隔离

仅少量明确匹配的本机当前用户数据目录可作为候选。程序再次扫描、二次确认并保存事务清单；隔离后可以尝试恢复。运行中的产品、托管软件、服务或驱动会阻止隔离。`Program Files`、`ProgramData`、驱动、服务、注册表以及计划任务均不自动删除。

## 常见失败

- **卸载器受限 / 签名不可信**：从 Windows 的“应用和功能”或 360 官方支持渠道尝试修复，不要使用来源不明的强制卸载器。
- **MSI 1603/1612**：卸载器损坏或安装源丢失，保留 MSI 日志，考虑官方修复安装再卸载。
- **MSI 1618**：其他 MSI 安装/卸载任务未结束，稍后再操作。
- **MSI 3010/1641**：重启后复查，不代表卸载前已彻底完成。
- **扫描不完整**：提升当前用户权限、恢复系统正常状态并重试，不能直接清理检查不到的内容。

**日志位置：** `%LOCALAPPDATA%\\Q360Cleanup\\Reports`。请勿向公共仓库上传未经脱敏的日志。
